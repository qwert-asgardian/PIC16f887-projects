# PIC16F887 Projects
This repository contains the PIC16F887 projects I worked on while learning Embedded C programming and microcontroller fundamentals.
The goal of these projects was to understand how hardware interacts with software through direct register-level programming and simulation using Proteus.

## Topics Covered
- LED Control
- Push Buttons
- 7 Segment Displays
- Keypads
- LCD Interfacing
- Interrupts
- Timers
- Counters
- PWM
- ADC

## Tools Used
- PIC16F887
- MPLAB X IDE
- XC8 Compiler
- Proteus

## Why I Built This
I created these projects as part of my embedded systems learning journey. Each folder represents a concept that helped me understand how microcontrollers work internally and how real-world embedded systems are developed.
