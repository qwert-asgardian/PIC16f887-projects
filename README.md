# PIC16F887 & STM32 Projects

Collection of Embedded C projects developed during Embedded Systems training using PIC16F887 and STM32 microcontrollers.

## Topics Covered

- GPIO
- LED Control
- Push Buttons
- 7 Segment Displays
- Keypad Interfacing
- LCD Interfacing
- Interrupts
- Timers
- Counters
- PWM
- ADC

## Tools Used

- MPLAB X IDE
- Keil uVision5
- Proteus
- PIC16F887
- STM32F103C6
